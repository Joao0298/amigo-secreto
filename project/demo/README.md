# 📹 Demonstrações do Amigo Secreto

Esta pasta contém materiais de demonstração do projeto.

## 🎥 Vídeo Demonstrativo

### Como gravar o vídeo (30 segundos):

1. **Preparação** (5s):
   - Abra a aplicação
   - Mostre a tela inicial limpa

2. **Adicionando Participantes** (10s):
   - Digite rapidamente 5 nomes:
     - Maria Silva
     - João Santos
     - Ana Costa
     - Pedro Oliveira
     - Carla Ferreira

3. **Realizando o Sorteio** (10s):
   - Clique em "Realizar Sorteio"
   - Mostre a animação de carregamento
   - Exiba os resultados

4. **Compartilhamento** (5s):
   - Demonstre os botões de compartilhamento
   - Clique em "Compartilhar via WhatsApp"

### Ferramentas Recomendadas:

**Windows:**
- [OBS Studio](https://obsproject.com/) (gratuito)
- [ShareX](https://getsharex.com/) (gratuito)
- [Camtasia](https://www.techsmith.com/video-editor.html) (pago)

**Mac:**
- [Kap](https://getkap.co/) (gratuito)
- [CleanShot X](https://cleanshot.com/) (pago)
- [ScreenFlow](https://www.telestream.net/screenflow/) (pago)

**Linux:**
- [SimpleScreenRecorder](https://www.maartenbaert.be/simplescreenrecorder/) (gratuito)
- [Kazam](https://launchpad.net/kazam) (gratuito)

### Configurações Recomendadas:
- **Resolução**: 1920x1080 (Full HD)
- **FPS**: 30 fps
- **Formato**: MP4 (H.264)
- **Duração**: máximo 30 segundos
- **Tamanho**: máximo 25MB para GitHub

## 📸 Capturas de Tela

### Lista de capturas necessárias:

1. **tela-inicial.png**: Formulário vazio pronto para adicionar nomes
2. **adicionando-participantes.png**: Formulário com alguns nomes já adicionados
3. **lista-completa.png**: Lista com todos os 5 participantes
4. **realizando-sorteio.png**: Tela de loading durante o sorteio
5. **resultados.png**: Resultados do sorteio exibidos
6. **compartilhamento.png**: Botões de compartilhamento em destaque
7. **whatsapp-preview.png**: Preview da mensagem no WhatsApp
8. **mobile-responsive.png**: Versão mobile da aplicação

### Dicas para boas capturas:

- Use resolução alta (pelo menos 1200px de largura)
- Capture em modo claro para melhor legibilidade
- Inclua dados realistas nos exemplos
- Mantenha consistência visual entre as capturas
- Use nomes fictícios mas realistas

## 🚀 Hospedagem do Vídeo

### Opções para hospedar o vídeo:

1. **GitHub** (recomendado para projetos pequenos):
   ```markdown
   ![Demo](demo/video-demo.mp4)
   ```

2. **YouTube** (melhor para SEO):
   ```markdown
   [![Demo](https://img.youtube.com/vi/VIDEO_ID/0.jpg)](https://www.youtube.com/watch?v=VIDEO_ID)
   ```

3. **Vimeo** (mais profissional):
   ```markdown
   [![Demo](https://vumbnail.com/VIDEO_ID.jpg)](https://vimeo.com/VIDEO_ID)
   ```

4. **GIF animado** (para preview rápido):
   ```markdown
   ![Demo](demo/demo.gif)
   ```
